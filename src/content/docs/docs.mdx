## Protocol compatibility

MCP Failure Lab uses MCP TypeScript SDK v2 and targets protocol version
`2026-07-28` for built-in scenario execution. The stdio and Streamable HTTP
servers also accept `2025-11-25` clients for compatibility.

The fault tools keep the same user-facing behavior across both protocol eras.
Protocol features that depend on the older server-initiated request model are
outside the current fault set.

See [External compatibility](/docs/compatibility/) for the versioned client matrix and known
transport-specific behavior.

:::note[Current scope]
Failure Lab runs scenarios against its built-in server or a configured external HTTP or stdio MCP
target. The built-in server provides malformed and duplicate JSON-RPC response faults. Session-loss
faults are not implemented.
:::
